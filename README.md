# Redis Interview Playbook

A self-contained, searchable Redis interview prep guide — 356 questions
across 23 topics + 15 system-design scenarios, aimed at Senior
Backend / Full-Stack interviews (Node.js, Express, NestJS, BullMQ,
microservices).

Each question includes a simple answer, a deeper explanation, a
real-world example, a production use case, an interview tip, likely
follow-up questions, common mistakes, and a short interview-ready
answer — with production-oriented ioredis/TypeScript/NestJS/BullMQ code
examples where relevant.

## Live site

Once GitHub Pages is enabled for this repo (Settings → Pages → Deploy
from branch → `main` → `/ (root)`), it will be live at:

https://therishabh.github.io/redis-interview-playbook/

## Usage

The whole guide is one file (`index.html`) — sidebar topic navigation,
live search, a "Final 15 — Must Prepare" bookmark section, and a
personal review-progress tracker (saved locally in your browser via
`localStorage`, not shared or synced anywhere).
